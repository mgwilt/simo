# MLX depth implementation map

T-106 complete read-only source/config/safetensors-header review by mlx_mapping. No files, exports, installs, GPU runs, services or commits changed. All mappings below were checked against the exact input paths in [T-106](../tasks/T-106.md); they establish a design, not numerical or performance acceptance.

All depth weights are BF16 in model-00001-of-00002.safetensors. Prefix is depth_decoder unless stated:

| Tensor suffix | Shape |
|---|---|
| model.embed_tokens.weight |[32816,2048] =16*2051 rows |
| model.inputs_embeds_projector.weight |[1024,2048] |
| codebooks_head.weight |[15,1024,2051] |
| model.layers.0..11.self_attn.q_proj/o_proj.weight |[1024,1024] |
| same k_proj/v_proj.weight |[256,1024] |
| model.layers.0..11.mlp.gate_proj/up_proj.weight |[8192,1024] |
| same down_proj.weight |[1024,8192] |
| layer norms and model.norm.weight |[1024], epsilon1e-5 |

Regular linears store[out,in]; each output head computes hidden @ head[step], without a transpose. No biases or backbone_hidden_state_projector. Serialized depth embedding is also the tied backbone audio embedding; backbone_model.embed_tokens.embed_audio_tokens.weight is intentionally absent. Heads are not tied.

Cache contract:12 layers,8 query/2 KV heads, head dimension128, split-half RoPE, GQA repetition4. Batch order conditional rows then unconditional rows. Prefill positions0/1 contain placeholder/c0; replace placeholder with branch hidden before2048->1024 projection. Embedding offset=max(position-1,0)*2051. Head s predicts c[s+1], using position s+1; final c15 never enters the cache. Reset K/V and step state each frame/failure; final paired cache per layer[2,2,16,128]. Mask future/unwritten positions, including causal prefill. Reject invalid shape/dtype/order.

Explicit reference rounding matters: RMSNorm computes F32 normalization, casts to BF16, then multiplies BF16 weight. SiLU produces BF16 before multiplying the up projection. Rotary frequencies/trigonometry use F32, cast cos/sin to BF16, then separate BF16 multiply/add. Llama3 parameters: theta500000, factor32, original context16, low0.001953125, high0.0078125; wavelength thresholds8192/2048. Eager attention preserves BF16 score/scaling, F32 softmax then BF16 probabilities. Fused RMSNorm/RoPE/SwiGLU/SDPA are numerical candidates, not assumed identical replacements.

Heads operate in model precision, then logits cast F32 for uncond+CFG*(cond-uncond). Mask tokens2048–2050. Sampling order: temperature, F32 softmax, top-k+renormalization, descending top-p retaining the crossing token+renormalization, multinomial. Do not reuse MLX-LM's differently ordered sampler. Depth has no repetition penalty; backbone codebook0 repetition processing remains unchanged. Same seed is not cross-framework sample equality: use teacher forcing, greedy paths and controlled distribution tests.

Dependency review: installed mlx0.32.0 requires mlx-metal0.32.0 on Darwin and no Transformers; installed mlx-lm0.31.3 requires Transformers>=5, incompatible with locked4.57.3. Use a standalone MLX-core module in an isolated pinned overlay. No dependency bypass/import-path trick or default lock upgrade. Reuse upstream concepts with attribution only where semantics match.

Next: root-owned weight loader, explicit operations/cache, heads/CFG/sampling and production probe. Validate exact names/shapes/dtypes/config; compare all15 heads across3 instruction-conditioned prefixes against full-prefix Torch reference, with branch/CFG max error, RMSE, relative L2, top1 and margin. Cover branch swapping, resets, invalid steps and filtering edge cases. Benchmark evaluated full depth+sampling, cold compile versus warm and Torch/MLX transfer cost. Non-depth work is already near64ms/frame, so a microbenchmark win is not Fast acceptance. Supports A-003/A-004/A-006 planning only; next mutation lease remains required.
