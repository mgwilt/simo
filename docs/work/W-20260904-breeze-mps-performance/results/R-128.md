## Safe artifact and export boundary

Never mount .artifacts, the deck directory or private key as static files. Serve opaque allowlisted clip IDs only. Reject client paths/URLs/query overrides, symlinks and traversal; bound manifest bytes, clip count and WAVs to mono24k PCM16/120 seconds. Validate the same complete bytes subsequently returned as PCM, avoiding separate-check/read races. Invalid/partial/changed audio remains unaccepted.

Require explicit per-clip heard-fully/not-fully/uncertain, intelligibility, missing/substituted/repeated/truncated words, instruction adherence, unnatural artifacts and audible gaps. Allow uncertainty, skips and incomplete sessions; preference includes ties. Hide ASR suggestions while rating. Keep replay counts, trial order and all attempts.

Only explicit browser download exports ratings, deck/clip identities, browser/player/build metadata and user-reported device/output/network conditions. No uploads, microphone permission or conversational-memory storage. Keep rendered/drained frames/queue underruns, output-clock estimate/callback fallback, listener-reported start/gaps and numeric acoustic onset separate. Numeric acoustic onset remains unmeasured without separately scoped capture/common-clock measurement and consent. Initial silence, mute, device/Bluetooth stalls and actual listening are not proved by worklet telemetry.
